# YouTube チャンネルの収益化判定

付属の `yt_monetize.rb` が全部やる。標準Ruby 2.6 と curl と、ログイン済みの**デバッグ用 Chrome**（CDP 9333）を使う。
**私の側では組み立て直さない。** 走らせて、出てきた表と要約行を伝えるだけにする。

## 実行

```bash
ruby ~/.claude/skills/yt-monetization-check/yt_monetize.rb "<チャンネルURL or @handle or UC…>" ["<2つ目>" ...]
```

- URL は `/shorts` `/videos` 付きでも、チャンネルトップでも、`@handle` だけでも、`UC…` のIDだけでもよい。日本語の @handle もそのまま渡せる。
- **コミュニティ投稿を取ったチャンネル全部**（`yt-community-posts` の保存先。各 `<名前>_投稿/投稿一覧.txt` の投稿URLからチャンネルを割り出す）：

  ```bash
  ruby ~/.claude/skills/yt-monetization-check/yt_monetize.rb --community-dir "/Users/daiki/Dropbox/【ボンビー】/⭐️美女レー・ヌーボー/コミュニティ投稿"
  ```

  保存先は `~/Desktop/コミュニティ投稿` ではなく、いまは上の Dropbox の下にある（42チャンネル、2026-09-28 時点）。
- 見る本数は**通常動画3本＋ショート5本**が既定（だいきんぐの指定）。変えるときは `--long N` `--shorts N`。
- `--tabs N`：デバッグ Chrome で同時に開くタブの数（既定3）。`--out FILE`：詳細を JSON で残す。`--no-thanks`：Chrome を使わず、ログインなしの段だけ見る。
- 42チャンネルで15〜25分かかる。**複数チャンネルは `run_in_background` で走らせて完了通知を待つ。**

## 判定のしかた

1. **ログインなし（curl）**：登録者数・動画数・動画一覧を取り、各動画のページに**この動画自身の商品タグ**（`productsInVideoOverlayRenderer` の中の `affiliateDisclaimerText`）があるかを見る。関連動画の分は拾わない。
2. **ログインあり（デバッグ Chrome）**：1で決まらなかったチャンネルだけ、動画を `watch?v=<ID>` の形で開き（ショートもこの形で開く。だいきんぐの指定）、「その他の操作」（…）を押してメニューに **Thanks** があるかを見る。通常とショートを交互に見て、見つかったらそのチャンネルは打ち切る。

Thanks もアフィリエイトも YPP 加入が条件なので、**1本でも出れば「収益化済み（確定）」**。

## 報告のしかた

- 「Thanks 出ず」は**未収益化ではない**と必ず添える。Thanks は動画ごと・チャンネルごとに切れる。ゴシップゥドルは4本中1本しか出なかったし、MKBHD は1本も出ない。登録者の多いチャンネルは「切っているだけ」の可能性が高い。
- **そのチャンネルが確定したことを示す動画（根拠の動画）**は表に出るので、そのまま示す。
- 確定したチャンネルの URL を求められたら、`https://www.youtube.com/channel/<UC…>` を**平文で1行ずつ**出す（表やコードブロックに包まない）。`--out` の JSON に `id` と `handle` がある。
- 自分のチャンネル（ログイン中のアカウントのもの）は、自分の動画に Thanks が出ないので判定できない。

## 当てにならないもの（試して外したもの）

- ページのソースの `is_monetization_enabled`：今は出ない。
- `adPlacements` / `adBreakHeartbeatParams`：YouTube は未収益化のチャンネルにも広告を出すので根拠にならない。ショートは動画と動画の間に広告が入るので、動画ごとの印も無い。
- メンバーシップの「メンバーになる」ボタン：任意の機能なので、無くても未収益化とは言えない。
- **ログインなし**のブラウザや curl で Thanks を探すこと：確実に出している大手でも出ない。ログインが要る。

## デバッグ用 Chrome

- 実体は Dog Imagine 用：`Google Chrome --remote-debugging-port=9333 --user-data-dir=~/.dog_imagine_chrome`。動いていなければスクリプトが同じ引数で起動する。
- **自分用のタブを開いて、終わったら閉じる。既存のタブには触らない**（Dog Imagine の作業中のことがある）。途中で止めても（INT/TERM）閉じる。`kill -9` だと残るので、そのときは `curl -s http://127.0.0.1:9333/json/list` で自分が開いた watch/shorts のタブを探して `/json/close/<id>` で閉じる。
- 「ログアウトしています」と出たら、パスワードは入れずに、だいきんぐにその Chrome でログインし直してもらう。

## 直すとき用（踏んだ所）

- **「…」を押してもメニューが開かないことがある**（3回に1回ほど。裏のタブだとほぼ開かない）。開かなかった回を「Thanks 無し」と数えると取りこぼす（実際に42チャンネルの初回判定で外した）。いまは次の3つで防いでいる。どれを外しても取りこぼしが戻る。
  - `Emulation.setFocusEmulationEnabled` で、裏のタブも前面にあるものとして扱わせる
  - メニューに必ずある「報告」が読めたときだけ、1本見たと数える。読めなければ押し直し、それでも駄目なら読み込みからやり直す
  - 項目は後から足される（Thanks が遅れて入る）ので、1秒変わらなくなるまで待ってから読む
- ログイン判定はアバター（`#avatar-btn`）ではなく `ytcfg.get('LOGGED_IN')` で見る。アバターは描画が遅れ、ログイン中でも「ログインしていない」と誤判定した。
- 通常動画の無いチャンネルは `/videos` にショートが並ぶので、同じ動画を二度見ないように重ねを除いている。
- フォルダ名は NFD（濁点が分かれた形）で来るので、名前は NFC にそろえてから比べる。そろえないと、名前での除外や照合から漏れる。
- システムRuby 2.6 なので `def x = …` の1行定義は使えない。`LANG` の無い環境で呼ばれても動くように、先頭で `Encoding.default_external` を UTF-8 にし、引数も `force_encoding("UTF-8")` している（LANG 無しだと ASCII-8BIT で来て、`--community-dir` の日本語パスで落ちた）。検証は `env -i PATH=/usr/bin:/bin HOME=$HOME ruby … --no-thanks` で空の環境でも通す。
