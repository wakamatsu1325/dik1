# 画像全面のモザイク

画像の**全面**をブロック化する。部分モザイクではない。

**この加工はガウシアンぼかしではない。** 以前ぼかしだと誤判定していたが、本人の確認と
画素レベルの再検証でモザイク（ブロック平均＋最近傍）と確定した。経緯は
`reference/calibration.md`。ぼかしで出すと「全然違う、正解はもっと荒い」となる。

出力は**原本より小さい**。この小ささ自体が仕様で、荒く見える主因はブロックサイズと
出力解像度の両方。等倍で出してはいけない。

## プリセット

ブロックの大きさは**原本の横幅に比例**する。だから解像度が変わっても見た目は変わらない。

| 記号 | 対象 | ブロック(横幅比) | 1536幅での実寸 | 根拠 |
|---|---|---|---|---|
| **P1** | 人物・強 | 1.30% | 20px | 本人が採用（2026-09-24 に1.01%から変更） |
| **M1** | 建物・非人物の既定 | 0.91% | 14px | 実測2組が一致 |
| **P2** | **人物の既定** | 0.90% | 14px | 本人が採用 |

**人物ならP2、建物・非人物ならM1。** 人物で「強め」ならP1。
CLIの `--level` 既定は人物想定のP2なので、建物・非人物を処理するときは `--level m1` を明示する。
P2とM1はほぼ同値（0.90% / 0.91%）だが、用途が違うので別記号のまま残す。
これより弱い設定は廃止。必要なら `--block-pct` で個別に指定する。

処理は「**原寸のままブロック平均 → 出力サイズへ縮小**」の順。逆にすると硬すぎて合わない。
出力は原本の約1/4（`--scale 0.25`）。この小ささも仕様の一部。

## 手順

```bash
python3 scripts/mosaic.py 画像.jpg                      # P2（既定）→ ~/Desktop/mosaic_P2_画像.jpg
python3 scripts/mosaic.py 画像.jpg --level p1           # 人物・強
python3 scripts/mosaic.py 画像.jpg --level m1           # 建物・非人物
python3 scripts/mosaic.py 画像.jpg --block-pct 1.5      # 任意の粗さ
python3 scripts/mosaic.py A.jpg B.png C.jpg             # まとめて処理
```

| オプション | 用途 |
|---|---|
| `--level p1` / `m1` / `p2` | プリセット（既定 p2） |
| `--block-pct 1.18` | ブロックを横幅比％で直接指定。`--level` より優先 |
| `--scale 0.25` | 出力の縮小率（既定 0.25） |
| `--out DIR` | 出力先（既定 `~/Desktop`） |
| `--quality 95` | JPEG品質 |

出力は常に別名で、**`mosaic_<強度>_<入力ファイル名>`**（`1.jpg` をP2で → `mosaic_P2_1.jpg`）。`--block-pct 1.5` のときは `mosaic_PCT1.5_1.jpg`。強度が名前に出るので別プリセットで出し分けても上書きにならない。**元ファイルは絶対に上書きしない。**
できたら `SendUserFile` で送り、出力サイズ・ブロック実寸・横幅比を一行で伝える。

### やり直しのときは初回の出力をゴミ箱へ

同じ原本を別の強度で出し直したら（「P1で」「強めで」など）、**新しい画像を送ったあとで**、
同じセッションで先に作った出力を `trash` コマンドでゴミ箱へ移す。確認は取らない。

```bash
trash ~/Desktop/mosaic_P2_1.png   # 先に出したほう。新しい出力は残す
```

- 捨てるのは、この会話で同じ原本から自分が作った出力だけ。原本や、以前の会話の出力には触らない。
- `rm` は使わない。ゴミ箱なら戻せるが、`rm` だと完全に消える。
- 送信する前には捨てない。送信に失敗したら、どちらの画像も残らなくなるため。
- 何を捨てたかを報告の一行に加える。

添付画像は `/private/tmp/claude-*/.../images/` に置かれているので、そのパスをそのまま渡せばいい。
ただし**割り込みで送られた画像はファイル化されないことがある**。`images/` に無ければ
本人に送り直してもらう。目視だけで強度を同定しようとしない。

## 「この見本と同じにして」と言われたら

見本と原本が両方あるなら同定できる。見本が切り抜き・縮小されていても対応位置を自動で探す。

```bash
python3 scripts/fit_mosaic.py 原本.png 見本.png
```

対応矩形・ブロックサイズ・局所勾配・残差を出す。出た `--block` と `--width` を
`mosaic.py` に渡せば再現になる。

### 数字だけで確定しない

3回連続で誤った出力を出した。原因は指標を信じたこと。

| 指標 | 何が起きたか |
|---|---|
| 残差（平均絶対差） | 常にガウシアンを選ぶ。モザイクは境界1pxのズレで差分が立つため |
| 局所勾配（画像全体） | 背景の白壁に引っ張られ、ブロックを小さく見積もる |
| **拡大目視** | これだけが正しく判定できた |

**必ず目で見る。** 正解と候補の同じ領域を6〜10倍の最近傍拡大で並べ、顔まわりで
ブロックの大きさを突き合わせる。`Read` ツールで自分で画像を開いて確認すること。

原本が特定できず残差が10を超えるようなら、その組はキャリブレーションに使わない。

## やらないこと

- ガウシアンぼかしで代用しない。`blur.py` は経緯として残してあるだけで、既定では使わない。
- モザイクを除去・復元しようとしない。この加工は隠す方向にしか進まない。
- 顔だけ・局所だけを処理しない。指示があれば別だが、既定は全面。
- 明度・彩度・コントラストを触らない。
- 等倍のまま出さない。縮小込みで仕様。
