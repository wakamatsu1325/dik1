# モザイク部分のマスク

モザイク（ピクセル化された領域）を、単色グレーの長方形1枚で完全に覆う。最終的に残っていいのは
「はみ出しゼロの長方形1枚」だけ。ここでの失敗はほぼ全て「覆い切れていない」であって
「覆いすぎ」ではないので、迷ったら広めに取る。

## 既定値

- 色: `#838383`（RGB 131,131,131）。既存の訴求画像で使っているグレーと同じ。指定がなければこれ。
- 形: 全領域を含む最小面積の長方形1枚。回転は許可（スクリプトが0.25°刻みで最小を探す）。
- 出力: `~/Desktop/<元のファイル名>_masked.png`。マスク済みを送ったら元画像はゴミ箱へ移す（手順5）。

## 手順

`scripts/mosaic_mask.py` を使う。`zoom` で見て、`mask` で塗る。それだけ。

### 1. サイズを見て、あたりをつける

```bash
python3 -c "from PIL import Image; im=Image.open('IMG'); print(im.size)"
```

添付画像そのものを一度見ているはずなので、モザイクがだいたい画像のどの辺にあるかは分かる。
表示で見た比率に画像の実寸を掛けて、粗い候補範囲を出す。

### 2. 拡大して境界を確定する

```bash
python3 scripts/mosaic_mask.py zoom IMG --box X0 Y0 X1 Y1
```

候補より一回り広く切って、出力された `/tmp/mosaic_zoom.png` を Read で実際に見る。
モザイクは「同じ色の正方形ブロックが格子状に並ぶ」ので、拡大すれば肌や布との境目は目で分かる。
スクリプトが座標換算式を print するので、拡大画像上で読んだ位置を元画像の座標に戻す。

自動検出は試さないほうがいい。JPEG圧縮やリサイズを経た画像ではブロックが完全な単色ではなくなり、
平坦度で探すと肌のハイライトや白飛びを拾って誤検出する。今回の対象は加工済みの配布画像なので、
拡大して目で見るほうが速くて確実。

### 3. 塗って、塗った結果をまた拡大して確認する

```bash
python3 scripts/mosaic_mask.py mask IMG --rect "X0 Y0 X1 Y1"
python3 scripts/mosaic_mask.py zoom ~/Desktop/NAME_masked.png --box ... --out /tmp/check.png
```

確認は必ず「塗った後の画像」を拡大して行う。塗る前の座標メモだけで判断すると、数pxの取りこぼしを
見逃す。実際、モザイクの端はぼかされて周囲と馴染んでいることが多く、1回目の範囲指定はだいたい
数px足りない。

はみ出しを見つけたら、追加の領域を `--rect` で足してもう一度 `mask` を実行する。複数指定すると
全部を含む最小の長方形1枚にまとめて塗ってくれるので、L字のまま残ることはない。

```bash
python3 scripts/mosaic_mask.py mask IMG --rect "150 440 208 496" --rect "208 472 222 496"
```

### 4. 渡す

`SendUserFile` で送り、保存先パスと塗った範囲（座標と色）を一行で伝える。
まだ足りないと言われたら、どの辺に何px足すかを聞くのではなく、自分でその方向を拡大して見てから
広げ直す。ユーザーに座標を計算させない。

### 5. 元ファイルをゴミ箱へ移す

マスク済みを送ったら、元画像を `trash` でゴミ箱へ移す（ユーザー指示、2026-09-23）。`rm` は使わない。

**消すのは1つとは限らない。** チャットに貼られた画像はセッションの `images/` にコピーが作られるだけで、
元ファイル（デスクトップの「スクエアショット YYYY-MM-DD HH.MM.SS.png」など）はそのまま残る。
`images/` 配下だけ消して終わりにしない。デスクトップも見て、添付と同じ画像があれば一緒に移す。

```bash
ls -lt ~/Desktop | head -20   # 添付の直前に作られたファイルが元画像
trash IMG "/Users/daiki/Desktop/スクエアショット ....png"
```

パスに空白が入るのでクォートを忘れない。同じ画像かどうかは、添付を見た時刻と `ls -lt` の更新時刻、
およびサイズ比で判断する。判然としないときだけ本人に確認する。

**バイト数では探さない。** 貼り付け時に PNG→webp 等へ変換されるので、`images/` のコピーと元ファイルはバイト数が一致しない
（実例: 元 1.37MB の「スクリーンショット 〜.png」が 99KB の webp になった）。`head` を短く切らずに添付時刻前の画像を並べ、
ピクセル寸法（縦横）が一致する候補を縮小表示して目で照合する。スクエアショットだけでなくスクリーンショットも候補。
「見つからない」で終わらせない。

後で塗り直しを頼まれたら、`~/.Trash/` から元画像を探して使う（同名がある場合は時刻付きの名前になっている）。

## 色を他の画像に合わせる場合

「この画像と同じ色にして」と参照画像を渡されたら、その画像のマスク領域を切って最頻色を取る。

```bash
python3 -c "
from PIL import Image; from collections import Counter
im=Image.open('REF').convert('RGB')
print(Counter(im.crop((X0,Y0,X1,Y1)).getdata()).most_common(5))"
```

マスクは単色なので最頻色がそのまま答えになる。周囲を含めて切ってしまっても、上位1件を見れば判別できる。
得た値を `--color '#RRGGBB'` に渡す。

## やらないこと

- モザイクを除去・復元しようとしない。この作業は隠す方向にしか進まない。
- 顔・ロゴ・テロップなど、モザイク以外の領域を勝手に塗らない。指示された対象だけ塗る。
- 元ファイルを上書きしない。出力は常に別名にして、元はゴミ箱へ移す（完全削除はしない）。
