# 3分割コラージュ（メイン1 + サブ2）

## レイアウト（既定 1408x1408）

- メイン画像: 上側 1408x920（全幅）
- サブ画像1: 左下 704x488
- サブ画像2: 右下 704x488
- 隙間・枠線なし。各枠へは枠を埋めるよう拡大して切り抜く（cover）

## 手順

1. まず**メイン画像**を依頼し、受け取ったら続けて**サブ画像2枚**を依頼する（1枚目=左下、2枚目=右下）。
2. 合成する:

```bash
python3 scripts/collage.py MAIN SUB1 SUB2 --out collage.jpg \
  --main "0.5 0.38" --sub1 "0.4 0.5 1.25" --sub2 "0.5 0.44 1.25"
```

   各オプションは `"FX FY [ZOOM]"`。FX/FY は枠の中心に来る元画像上の点（0〜1の比率）、
   ZOOM は寄り具合（1=枠を埋める最小、大きいほど寄る）。画像外にはみ出す指定は自動で内側に戻る。

3. 出力を Read で見て確認する。見るポイント:
   - 顔（目・口・顎）が枠の端で切れていないか
   - モザイク/グレーの帯などが枠の端に**細く**だけ映り込んでいないか（入れるならしっかり、避けるなら完全に外す）
   - 問題があれば FX/FY/ZOOM を調整して再実行

素材は正方形前提だが、正方形でなくても cover で切り抜くのでそのまま使える。
