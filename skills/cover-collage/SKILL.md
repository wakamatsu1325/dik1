# 3分割コラージュ（メイン1 + サブ2）

## レイアウト（既定 1408x1408）

- メイン画像: 上側 1408x845（全幅、`--main-ratio 0.60`）
- サブ画像1: 左下 704x563
- サブ画像2: 右下 704x563
- メインとサブの高さ配分は `--main-ratio` で変える（参考元の画像は 920/1408 ≈ 0.653）
- 隙間・枠線なし。各枠へは枠を埋めるよう拡大して切り抜く（cover）

## メイン画像の選び方

- 3枚まとめて渡された場合、**ファイル名に「エース」が含まれる画像をメイン**にする。
  - チャットに添付された画像は 1.jpg/2.jpg/3.jpg に改名されていて、元のファイル名は分からない。
    **ファイル名ではなく中身で探す**：直近2時間に更新された画像の md5 を取り、添付と一致したファイルの名前に「エース」が入っているかを見る（本人に聞かない）。
    見る順番は ①デスクトップ（`~/Desktop`）→ ②`/Users/daiki/Dropbox/【ボンビー】/⭐️美女レー・ヌーボー/🍷訴求`。①で見つかれば②は見ない。
    デスクトップ直下だけを名前で探して「無い」と判断しない（2026-09-26、元画像が `🍷訴求/まみちゃん/エース.jpg` にあって見落とした）。

```bash
S=<session>/images
for d in ~/Desktop "/Users/daiki/Dropbox/【ボンビー】/⭐️美女レー・ヌーボー/🍷訴求"; do
  find "$d" -type f \( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.png' -o -iname '*.webp' \) -mmin -120 2>/dev/null \
    | while read f; do echo "$(md5 -q "$f") $f"; done
done
md5 -q $S/*.jpg   # 添付側。一致した行のファイル名に「エース」があればそれがメイン
```
- 残り2枚は渡された順に左下・右下へ。
- 「エース」入りが無い、または複数ある場合は、どれをメインにするか確認する。

## 手順

1. 3枚まとめて届いたら上のルールでメインを決める。別々に届く場合は、まず**メイン画像**を依頼し、受け取ったら続けて**サブ画像2枚**を依頼する（1枚目=左下、2枚目=右下）。
2. 合成する:

```bash
python3 scripts/collage.py MAIN SUB1 SUB2 --out collage.jpg \
  --main "0.5 0.4" --sub1 "0.42 0.5 1.25" --sub2 "0.55 1.0 1.2"
```

   各オプションは `"FX FY [ZOOM]"`。FX/FY は枠の中心に来る元画像上の点（0〜1の比率）、
   ZOOM は寄り具合（1=枠を埋める最小、大きいほど寄る）。画像外にはみ出す指定は自動で内側に戻る。

3. 出力を Read で見て確認する。見るポイント:
   - 顔（目・口・顎）が枠の端で切れていないか
   - モザイク/グレーの帯などが枠の端に**細く**だけ映り込んでいないか（入れるならしっかり、避けるなら完全に外す）
   - 口元を見せたい指定なら、モザイクで隠れていても口元のモザイクごと枠内に入れる
   - 問題があれば FX/FY/ZOOM を調整して再実行

素材は正方形前提だが、正方形でなくても cover で切り抜くのでそのまま使える。

## 3分割の印（Dog URL の集計表用）

`collage.py` は出力に **`DogURL:split3` の印**を書き込む（JPEGはコメント、PNGはテキスト。見た目は変わらない）。
Dog URL で投稿すると、1枚目がこの印付きかどうかが集計表の「1枚目3分割」列に自動で入る。

- **出力は `.jpg` か `.png` にする。** それ以外（`.webp` 等）では印を書けず、警告が出る
- 合成した画像を**別のツールで保存し直すと印が落ちることがある**（mosaic-mask・photo-blur は印を引き継がない）。
  合成の後で加工したときは、Dog URL 側で `ruby bin/shorten.rb split <短縮URL> 3分割` と手で入れる
  （手順は yt-stats-apply スキル）
