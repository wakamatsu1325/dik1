# 動画内のテロップを文字起こしする

## 絶対ルール

- **0.3秒に1コマ（fps=10/3）で全コマを見る。** 2秒・1秒おきでは、短く出るテロップ（「いるんだ。」「最強の？」など）を必ず見落とす。
- 全コマを見終えてから書く。コマの連続は同じテロップなので重複は1つにまとめる。
- 出力に**番号は付けない**。1テロップ1行、出てくる順。赤字などの装飾注記も不要。

## 手順

1. 作業はスクラッチパッドで行う。動画は `ffprobe` で長さを確かめる。
2. テロップ領域だけ切り出してコマを書き出す（tesseract は無いので目視で読む）。まず1コマ見て、テロップの位置を決める:
   ```
   ffmpeg -v error -i <動画> -vf "fps=10/3,scale=640:-1,crop=W:H:X:Y" g/%03d.png
   ```
   - 横幅いっぱいに出る字幕は crop を広げる。画面端で切れていないか確認する。
3. PIL で20コマずつ（4列×5行）のコンタクトシートにし、各タイルに通し番号を描く。`python3 -I` で実行。
4. `Read` でシートを順に全部見る。ffmpeg の tile は連番出力でエラーになりやすいので、PIL で組む。
5. 小さい字（画面下の黄色字幕など）は、該当コマを元解像度で crop して拡大して読む。判読できないものは「確実ではない」と添える。
6. 返答: テロップを番号なしで時系列に列挙。画面端で切れている文字、判読に自信がない文字は末尾に注記する。
