# クリック数が伸びやすい作品・投稿文の傾向を分析する

作業場所は `/Users/daiki/Desktop/Dog URL`。材料は `~/Library/Application Support/Dog URL/` の
`clicks.json`・`history.json`・`runs/*.json`・`notes.json` と、集計表 `~/Desktop/Dog URL 集計.xlsx`（作品の属性・売れた数・1枚目の画像）。

## 手順

### 1. クリック数を今読む

集計中の投稿の位置を今の値で出すため、先に直近の分を積む。

```bash
cd "/Users/daiki/Desktop/Dog URL" && ruby bin/shorten.rb stats --days 3
```

`timeout` コマンドは無い（macOS）。付けない。

### 2. 分析する

```bash
/usr/bin/ruby ~/.claude/skills/click-trends/trends.rb
```

読むだけで何も書かない。出るもの:

- 24時間の順位表（80分・3時間・売れた数・YTインプ・区分・1枚目・投稿時刻・投稿文・作品）
- 属性ごとの はい／いいえ の比較（件数・24時間の中央値・中央値以上の件数）。差が全体の中央値の3割以上なら ▲▼
- ▲▼の属性どうしの重なり（同じ投稿群に偏っていて、どちらが効いたか分けられない組）
- 1枚目の画像の登場人物ごとの値（2回以上出た登場人物だけ）
- 2回以上使った言い回し（投稿文の1行目から自動で拾う）と、それが全部中央値以上／全部未満／混在か
- 序盤（80分・3時間）と24時間、24時間と売れた数・YTインプの順位相関
- 前半と後半の中央値（時期による差）
- 集計中の投稿の、同じ経過時間の全投稿の中での順位
- 末尾の ⚠（集計表が古い・行が無い・「1枚目3分割」が空）

### 3. ⚠ が出たら

- `集計表に行が無い投稿` または `集計表より新しい投稿がある` → 集計表を書き直してから手順2を流し直す。
  `ruby bin/shorten.rb sheet`（売れた数も読む。デバッグChromeが要る。起きていなければ `ruby bin/shorten.rb chrome`）。
  報酬が読めなかったら、売れた数の列は空のまま進めて、そのことを答えに書く
- `「1枚目3分割」が空の行` → その行は3分割の比較から外れる（空を「なし」と数えない）。空が多いうちは3分割の効果を言わない。
  埋めるなら yt-stats-apply スキル（`ruby bin/shorten.rb split <短縮URL> 3分割|なし`）。勝手に埋めない。本人に確かめる

## 決まり

- **物差しは投稿から24時間後のクリック数（投稿後）。** 経過時間のそろえ方は click-growth と同じ
  （起点は `mark: post`、無ければ生成時刻。前後の記録が狭ければ補間、広ければ ±25% 以内の実測）。
  それでも取れない投稿は前後の記録を直線で結び、`*` を付ける
- 外すもの（スクリプトが自動で外す）: 備考（`notes.json`）に「削除」と入った投稿、子リンク、序盤の記録が無い初期の投稿、24時間未満の投稿（集計中の欄へ回す）
- 属性は投稿文の1行目（`runs` の `text_a`）と集計表の列から決める。属性を足すときは `trends.rb` の `FACTORS` へ足し、
  **分からない投稿には `nil` を返す**（比較から外れる）。`=~` は一致しないと `nil` になり「不明」扱いされるので、真偽は `match?` で返す

## 読み方の決まり

- **件数が少ないので、出るのは「傾向の候補」まで。** 法則と言わない。▲▼でも はい が2〜4件なら件数を添える
- **▲▼の重なりの欄に出た組は、効いた方を決めない。**「素人・作品フォルダの画像・問いかけ文が同じ投稿群に集まっていて分けられない」と書く
- 1つの属性の中で当たりと外れが両方あれば（例: 問いかけ文でも偽えなこは削除）、中身の違いを並べて、言い回しだけの効果と言わない
- 上位3件と下位3件は名前（作品・女優・投稿文）を出して、共通点を具体的に言う。
  上位にも下位にも出る属性（「美女」など）は効いていないとみなす
- 「2回以上使った言い回し」で **全部中央値未満** の言い回しは、避ける候補として挙げる（件数を添える）
- 序盤と24時間の相関が高い（0.8以上）うちは「最初の1〜3時間でほぼ決まる」と言ってよい
- 1枚目の画像の中身（顔・構図）はスクリプトでは見ていない。画像の良し悪しを傾向として言わない
- **物差しが2種類ある**（2026-09-29 から）。TinyURL の投稿は同じ回線のクリックを丸めて少なめ、X.gd は踏んだ回数どおり。
  スクリプトは X.gd の投稿に順位表で ` x` を付け、混ざっていれば冒頭に ⚠ を出す。
  X.gd の投稿が上位に来ても、属性の効果と言う前に物差しの差でないかを疑う。**「時期（前半と後半）」の差も物差しの切り替えと重なる**ので、
  X.gd の投稿が混ざっているうちは時期の差を結論にしない
- 集計中の投稿は同じ経過時間での順位だけ言う。24時間の見込みを出したいなら click-growth を使う

## 答え方

1. 対象の件数と24時間の中央値・上位1/4の境・下位1/4の境を1行で
2. 上位と下位の顔ぶれ（表。24時間・投稿文・作品）
3. 傾向として言えそうなこと（3〜5個。各項目に件数と中央値を添える。重なりで分けられないものはそう書く）
4. 差が見えなかったもの（1行でまとめる）
5. 注意点（重なり・件数・画像の中身は見ていないこと）。⚠ が出ていればここで書く
6. 集計中の投稿の位置（あれば）
7. 最後に、分けられていない要素を切り分ける次の一手を1つ（例: 同じ素人作品で1枚目の3分割だけ変える）
