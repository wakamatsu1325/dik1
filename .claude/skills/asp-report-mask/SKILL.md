# ASPレポートのマスク

日次レポート（上部に「現在の設定／集計期間」、中央にHighchartsのグラフ、下に「期間合計」の集計表）の
スクショから、報酬額まわりの情報だけを消す。**クリック数・件数・金額の数字そのものは残す**のが
この加工の要点で、消すのはグラフと項目名と単位だけ。

## 仕様（3点。これで完全再現になる）

1. **グラフ領域を丸ごとガウスぼかし**（半径 = 画像幅/87）
   左右の軸ラベル・凡例・「クリック」「報酬金」の見出しまで枠いっぱいに含める。
   下端は横軸のラインまで。**横軸の 0〜23 とNO.1バッジ、Highcharts.com は残す**。
2. **集計表ヘッダーの3列目以降をセル単位でぼかし**（半径 = 画像幅/78）
   1列目（空欄）と2列目「● クリック数」は残す。3列目以降＝ダイレクト報酬／カテゴリ報酬／
   サービス新規報酬／報酬合計。セルごとに別々にぼかすので区切り線は残る。
3. **金額末尾の「円」を単色グレー `#d2d2d2` の矩形で塗り潰す**（左右+4px、上下+5px）
   数字（1,138 や 3,534）と「件」はそのまま。潰すのは単位の一文字だけ。

比較用の仕上がり見本: `reference/sample_masked.png`

## 手順

```bash
python3 scripts/report_mask.py detect IMG    # 検出座標の確認（任意）
python3 scripts/report_mask.py mask   IMG    # → ~/Desktop/<元名>_masked.png
```

座標は全部自動検出する（黒帯を数えて集計表ヘッダーを特定 → 枠・列区切り・数値行 →
グラフ上端は凡例行の25px上、下端は幅の7割以上が非白になる一番下の行＝横軸ライン）。
解像度が違うスクショでも比率で追従する。

最後に必ず出力画像を Read で見て、

- 横軸の数字が消えていないか（消えていたら下端の検出ミス）
- ヘッダーの文字が読めないか
- 「円」が残っていないか

を確認してから `SendUserFile` で渡す。

## オプション

- `--keep-cols N` … ぼかさずに残すヘッダー列数（既定2）。表の構成が違う時だけ触る。
- `--no-yen` … 「円」の塗り潰しを省く。
- `-o PATH` … 出力先。既定は `~/Desktop/<元名>_masked.png`。

## 自動検出が外れた場合

`detect` の出力を見て、どの値がおかしいかを特定してから、その場で座標を直書きして処理する。
スクリプトを無理に直すより早い。

```python
from PIL import Image, ImageFilter, ImageDraw
im = Image.open(SRC).convert("RGB")
blur = lambda box, r: im.paste(im.crop(box).filter(ImageFilter.GaussianBlur(r)), box)
blur((LEFT, CHART_TOP, RIGHT, CHART_BOT), round(im.width/87))
for x0, x1 in COLS:
    blur((x0, HDR_TOP-6, x1, HDR_BOT+6), round(im.width/78))
d = ImageDraw.Draw(im)
for l, t, r, b in YEN:
    d.rectangle([l-4, t-5, r+4, b+5], fill=(210, 210, 210))
im.save(OUT)
```

よくある外し方は下端で、`chart_bot` が大きすぎると横軸の 0〜23 まで消える。
表の枠線を横軸ラインと誤認している時は `limit` より下を見ているので、`chart_bot` を
横軸ラインの実測値+12 に固定すればいい。

## やらないこと

- 数字（クリック数・件数・金額）を消さない。伏せるのは項目名・単位・グラフの形だけ。
- 元ファイルを上書きしない。
- 局部モザイクの塗り潰しは別スキル（mosaic-mask）。用途が違うので混ぜない。
