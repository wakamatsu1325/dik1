# 顔だけぼかし

指定した人物の顔の部分だけを、楕円形にガウシアンぼかしする。背景・体・指定外の人物はそのまま。
画像全体のモザイクは `photo-blur`、局部モザイクの塗り潰しは `mosaic-mask`。

## 強さ

| 呼び方 | `--sigma` | 備考 |
|---|---|---|
| 強め | 28 | 最初の版（青い服の女性） |
| **既定（弱め）** | **12** | 「もっと弱くして」で決まった強さ。指定がなければこれ |

ユーザーが「もっと弱く／強く」と言ったら、この値を目安に増減して出し直す。

## 手順

1. 添付画像（`.../images/N.jpg`）を `Read` で開き、**ぼかす顔を特定**する。「右の人物以外の全員」「青い服の女性」などの指定を、画像上の人物に当てはめる。
2. 各顔について、**髪の生え際から顎まで・耳まで入る楕円の外接矩形** `x0,y0,x1,y1`（原寸ピクセル）を決める。目安は顔の大きさより一回り大きく。
   - 後ろ向き・横向き・頭しか見えない人も、指定の対象なら頭の範囲をぼかす。
   - 小さく奥にいる人・髪だけ見える人も忘れない。
3. 実行する。
   ```bash
   python3 /home/user/dik1/.claude/skills/face-blur/scripts/face_blur.py 画像.jpg \
     --box 535,470,815,800 --box 0,215,155,385 \
     --out <scratchpad> --name 元の名前 --crop 0,180,720,460
   ```
   - 初回は `pip install pillow` が要ることがある。
   - `--sigma` で強さ、`--crop` で確認用の2倍切り抜きを出す。
4. **必ず出力を `Read` で目視**する（顔のはみ出し・取りこぼしが無いか。複数人のときは `--crop` で集団を拡大して見る）。足りなければ box を直して出し直す。
5. 仕上がりを次の2か所へ出す（CLAUDE.md の約束）。
   - `SendUserFile`（display: render）で**このチャット内**に出す。
   - `dik1-downloads` の `downloads/` へ置いて `main` へ push（Mac のデスクトップへ自動で移る）。手順は CLAUDE.md のとおり。

## 出力

`blur_face_<元の名前>.jpg`（原寸のまま、元は上書きしない）。やり直しは別名（`_weak` など）で出して構わない。

## やらないこと

- 顔以外の場所（体・背景）をぼかさない。指定のない人物の顔をぼかさない。
- 全面モザイクで代用しない（それは `photo-blur`）。
- ぼかした顔を復元しようとしない。
